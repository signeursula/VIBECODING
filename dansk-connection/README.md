## Danish Connection
I love the NYT's puzzle games, including the game Connection. I loved it so much, that I wanted to make a Danish version. The whole code is made with Claude, but the words I made myself. I had so much fun coming up with the categories, and I feel like that is the important part to be human. I like that the human-in-the-loop has the creative part, and then Claude can take care of the technical building-part.
